# Nabu AI Plus Landing Page

This folder contains the landing page and download page for Nabu AI Plus Chrome Extension.

## Files

- `index.html` - Main landing page with features and information about Nabu AI Plus
- `download.html` - Download page with installation instructions and extension ZIP download
- `style.css` - Styling using shadcn design system tokens
- `nabu-ai-plus-extension.zip` - Chrome extension package (generated by build script)

## Building the Extension ZIP

To create the extension ZIP file for download:

```bash
# Build the extension and create the ZIP file
npm run build:landing

# Or separately:
npm run build:extension
npm run create:zip
```

The ZIP file will be created at `landing/nabu-ai-plus-extension.zip`.

## Viewing the Landing Page

You can view the landing page by opening `index.html` in a web browser. For local development with a server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js http-server
npx http-server -p 8000
```

Then navigate to `http://localhost:8000/landing/` in your browser.
